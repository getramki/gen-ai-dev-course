# Enhanced Home Loan EMI Calculator MCP Server

An enhanced MCP server with tools, resources, and prompts for comprehensive home loan assistance.

## Features

### Tools
- `calculate_home_loan_emi`: Calculate EMI, total amount, and interest

### Resources
- `emi-formula`: EMI calculation formula and explanation
- `interest-rates`: Current home loan interest rates in India
- `loan-eligibility`: Home loan eligibility criteria and requirements

### Prompts
- `emi-advisor`: Prompt for EMI advisory assistance
- `loan-comparison`: Prompt for comparing different loan options

## Installation

```bash
pip install fastmcp
```

## Usage

### With MCP Inspector
```bash
npx @modelcontextprotocol/inspector python server.py
```

### Direct Usage
```bash
python server.py
```

## Example Usage

The server provides comprehensive home loan assistance including EMI calculations, current interest rates, eligibility criteria, and advisory prompts for AI assistants.
