# Home Loan EMI Calculator MCP Client

An MCP client that connects to the Home Loan EMI Calculator server.

## Installation

```bash
pip install -r requirements.txt
```

## Usage

1. Ensure the server is available at `../hl-emi-calc-server/server.py`
2. Run the client:
```bash
python client.py
```

The client will prompt for loan details and display the EMI calculation results from the server.
