# Module 1: LangChain Fundamentals (20 minutes)

## Learning Objectives
- Understand LangChain architecture and core concepts
- Master LangChain Expression Language (LCEL) basics
- Implement memory and context management
- Build foundational skills for AWS Bedrock integration

## Prerequisites
- Python 3.8+
- Basic understanding of AI/ML concepts
- Familiarity with Python programming

## Module Structure
1. **Topic 1.1**: Introduction to LangChain Architecture (5 min)
2. **Topic 1.2**: Core Components: LLMs, Prompts, and Chains (6 min)
3. **Topic 1.3**: LangChain Expression Language (LCEL) Basics (5 min)
4. **Topic 1.4**: Memory and Context Management (4 min)

## Setup Instructions
```bash
# Create virtual environment
python -m venv langchain-env
source langchain-env/bin/activate  # On Windows: langchain-env\Scripts\activate

# Install dependencies
pip install langchain langchain-core langchain-community python-dotenv
```

## Files in this Module
- `topic_1_1_architecture.py` - LangChain architecture exploration
- `topic_1_2_core_components.py` - LLMs, prompts, and chains
- `topic_1_3_lcel_basics.py` - LCEL syntax and operations
- `topic_1_4_memory_context.py` - Memory and context management
- `exercises/` - Hands-on practice files

## Quick Start
Run each topic file to see LangChain concepts in action:
```bash
python topic_1_1_architecture.py
python topic_1_2_core_components.py
python topic_1_3_lcel_basics.py
python topic_1_4_memory_context.py
```
