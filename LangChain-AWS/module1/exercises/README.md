# Module 1 Exercises

## Overview
This directory contains hands-on exercises for Module 1: LangChain Fundamentals.

## Exercise Files

- **Code File**: `exercise_1_basic_chain.py`
- **Instructions**: `exercise_1_instructions.md`
- **Time**: 5 minutes
- **Focus**: LCEL composition, parallel processing, text analysis

### 📝 **Exercise 2: Conversation Memory System**

## Quick Start

### Run Exercises
```bash
# Navigate to exercises directory
cd module1/exercises

# Run Exercise 1
python exercise_1_basic_chain.py

# Run Exercise 2
python exercise_2_memory_system.py
```

### Read Instructions
```bash
# View Exercise 1 instructions
cat exercise_1_instructions.md

# View Exercise 2 instructions
cat exercise_2_instructions.md
```
