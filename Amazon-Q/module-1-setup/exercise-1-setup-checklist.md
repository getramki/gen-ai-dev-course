# Exercise 1: Setup Checklist

## Pre-Installation Checklist

### System Requirements
- [ ] Operating System: Windows 10+, macOS 10.14+, or Linux
- [ ] IDE: VS Code 1.74+ or IntelliJ IDEA 2022.1+
- [ ] Internet connection for authentication
- [ ] AWS account (free tier is sufficient)

### Account Preparation
- [ ] AWS account created at aws.amazon.com
- [ ] Email verified for AWS account
- [ ] Note down your AWS account email

---

## Installation Verification

### VS Code Installation Steps
1. [ ] Open VS Code
2. [ ] Press Ctrl+Shift+X (Cmd+Shift+X on Mac) to open Extensions
3. [ ] Search for "Amazon Q"
4. [ ] Verify you see "Amazon Q" by Amazon Web Services
5. [ ] Click "Install"
6. [ ] Wait for installation to complete
7. [ ] Look for Amazon Q icon in Activity Bar (left sidebar)

### IntelliJ IDEA Installation Steps
1. [ ] Open IntelliJ IDEA
2. [ ] Go to File → Settings (IntelliJ IDEA → Preferences on Mac)
3. [ ] Navigate to Plugins
4. [ ] Click "Marketplace" tab
5. [ ] Search for "Amazon Q"
6. [ ] Click "Install" next to Amazon Q plugin
7. [ ] Restart IntelliJ when prompted
8. [ ] Verify Amazon Q appears in Tools menu

---

## Authentication Process

### Step-by-Step Authentication
1. [ ] Click on Amazon Q icon/menu item
2. [ ] Select "Sign in to get started"
3. [ ] Choose "Use AWS Builder ID" (recommended)
4. [ ] Click "Continue to Browser"
5. [ ] Complete browser authentication:
   - [ ] Enter email address
   - [ ] Check email for verification code
   - [ ] Enter verification code
   - [ ] Complete profile setup
6. [ ] Return to IDE
7. [ ] Verify "Connected" status appears

### Verification Steps
- [ ] Amazon Q chat panel is accessible
- [ ] Status bar shows Amazon Q connection
- [ ] No error messages in IDE
- [ ] Can type in Amazon Q chat

---

## First Interaction Test

### Basic Chat Test
Type this in Amazon Q chat:
```
Hello! Can you help me write a simple Python function?
```

Expected response should:
- [ ] Acknowledge your request
- [ ] Offer to help with Python code
- [ ] Show Amazon Q is responsive

### Code Generation Test
Type this request:
```
Write a Python function that adds two numbers
```

Verify the response:
- [ ] Contains a Python function
- [ ] Function has parameters for two numbers
- [ ] Function returns the sum
- [ ] Code is syntactically correct

---

## Troubleshooting Checklist

If you encounter issues, check:

### Authentication Issues
- [ ] Internet connection is stable
- [ ] Browser allows pop-ups from IDE
- [ ] AWS account email is verified
- [ ] Try signing out and back in

### Extension Issues
- [ ] IDE is up to date
- [ ] Extension is enabled (not disabled)
- [ ] Restart IDE after installation
- [ ] Check IDE error logs

### Connection Issues
- [ ] Firewall allows IDE internet access
- [ ] Corporate proxy settings configured
- [ ] VPN not blocking connections
- [ ] Try different network if available
